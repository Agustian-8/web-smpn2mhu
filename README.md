# Website SMP Negeri 2 Matan Hilir Utara

Website resmi SMP Negeri 2 Matan Hilir Utara, Kabupaten Ketapang, Kalimantan Barat.

## Fitur

- Beranda dengan hero dan berita terbaru
- Profil sekolah (identitas, sejarah, visi misi, fasilitas, tenaga pendidik)
- Akademik (PPDB, kurikulum, kalender, ekstrakurikuler)
- Berita dan pengumuman
- Kontak dan lokasi
- PPDB online dengan formulir pendaftaran
- Admin panel untuk mengelola berita dan data pendaftar

## Teknologi

- Next.js 16
- TypeScript
- Tailwind CSS
- Google Apps Script (backend)
- Google Sheets (database)
